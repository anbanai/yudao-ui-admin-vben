# 轮播图固定高度约束修复设计

## 问题

店铺装修的轮播图属性已有 `height` 配置，但 Ant Design Vue Carousel 只把高度设置在最外层轮播节点。轮播项内部的包裹元素没有继承该高度，图片会按自身固有比例撑开内容，导致：

- 编辑器中图片内容高度与配置高度不一致，底部出现大块空白；
- 依赖该配置渲染的小程序页面可能继续按图片自然高度布局，表现为页面被拉长。

## 目标与非目标

目标是修复现有固定高度的实现，使配置值成为轮播内容的实际高度，并保持现有图片 `object-cover` 语义，避免图片变形。

非目标是新增自适应高度、修改属性面板、改变已保存数据格式，或改变轮播指示器/自动播放等行为。

## 设计

在 `apps/web-antd/src/views/mall/promotion/components/diy-editor/components/mobile/carousel/index.vue` 中：

1. 为每个轮播项的包裹元素设置 `height: ${property.height}px`，并确保它占满宽度。
2. 让 Ant Design Vue 的 `.slick-list`、`.slick-track`、`.slick-slide` 继承配置高度，避免内部轨道根据图片固有尺寸重新撑高。
3. 将图片设为块级元素并使用 `height: 100%; width: 100%; object-fit: cover`，保证固定框内填充且不变形。
4. 空数据占位逻辑保持现状；属性面板和导出的页面配置不变。

## 验证

增加一个针对轮播高度约束的回归测试，验证组件源码/渲染结构包含固定高度的轮播项容器和内部轨道约束；测试先在未修复代码上失败，再在修复后通过。随后运行该测试与 web-antd 类型检查。

## 备选方案

- 只给图片设置 `max-height`：无法约束 Carousel 轨道，仍可能保留额外空白。
- 改为 `object-contain`：会改变现有轮播图的视觉语义并产生留白，不属于本次 bug 修复范围。
- 改为自适应高度：与已有固定高度配置冲突，属于需求变化。
