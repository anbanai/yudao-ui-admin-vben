# 登录页内容移除设计

## 目标

从共享登录组件中移除登录界面的“其他方式登录”和“萌新必读”两块内容，同时保留现有账号密码、验证码、二维码、注册、找回密码及登录提交逻辑。

## 范围与方案

- 修改 `packages/effects/common-ui/src/ui/authentication/login.vue`。
- 移除第三方登录组件及其事件处理、模板插槽内容，使“其他方式登录”不再渲染。
- 移除“萌新必读”文档链接组件的导入和模板节点，使该入口不再渲染。
- 不修改认证接口、路由、登录表单字段、登录方式开关或国际化资源。
- 由于该组件由多个应用主题复用，改动对所有复用它的登录页统一生效。

## 验收标准

1. 登录页不显示“其他方式登录”区域。
2. 登录页不显示“萌新必读”入口。
3. 账号密码登录及其他保留的登录入口代码仍能通过类型检查/构建校验。
4. 工作区已有的无关改动不被修改。

## 验证

运行共享组件相关的 lint 或类型检查；若仓库级检查成本可接受，再运行对应应用构建，确认模板和导入清理完整。
