# 营销中心管理端接入设计（CMP-102）

沿用已授权实施范围与 CMP-106 契约，在 apps/web-antd 原有页面补齐功能；复用会员列表、模板选择、SPU/SKU选择、DIY注册及现有权限。其他UI应用、CMP-87分享封面和已有商品推广改动不变。

发券统一经过 send-preview、后台模板与账号快照展示、管理员明确确认、send-submit。同一批次防重复点击。取消预检不发券（后台允许留下惰性预检记录）。手机号导入只做格式/去重，账号存在性和标签并集以服务端预检为准。失败批次不能提交。

未知提交在 sessionStorage 仅保存批次ID，重开/刷新优先恢复。status0可能是尚未提交事务的旧读，不能据此解除保护；未知批次仅查询或同批次重试。成功status1后解除保护。当前后端缺少确定失败终态，模板变更后的安全作废仍需后端补齐。

模板支持兑换绑定及叠加；兑换保存强制单SKU、禁止叠加。推广由后台生成，直接展示后台miniProgramPath。DIY NewcomerCoupon保存templateId/title/buttonText/style，选择时读取后台真实模板校验，资格留给后端。

积分沿用配置、等级及流水页面：倍率以整数百分比存储；双倍时间支持星期/跨午夜/时区，文案与后台固定2倍/向下取整规则一致；有效天数默认365。统计不受列表筛选影响，展示后台返回的累计发放、消耗、可用和过期。

采用扩展既有页面。新建独立营销应用会重复路由和权限；前端自行判断资格/统计将偏离后台快照，均不采用。
