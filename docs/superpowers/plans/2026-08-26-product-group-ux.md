# 商品分组 UX 优化计划

## 目标

在不改变 ProductGroup 数据协议、查询缓存和旧 ProductList 行为的前提下，提升小程序端分类导航、商品卡片密度和加载/空状态的可读性；同步修正装修预览 Tabs 的点击层级。

## 实施范围

1. 小程序 `s-goods-group` 增加稳定的菜单视觉层级、加载与空状态，并将商品分组标识传给共享货架渲染器。
2. `s-goods-shelves` 增加 ProductGroup 专属样式入口；通过 `s-goods-column` 的可选标题行数支持两行标题，不改变其他商品栏调用方。
3. 管理端 ProductGroup 预览 Tabs 始终建立定位层级，避免非吸顶状态被装修容器遮挡。

## 验证

运行商品分组测试、小程序 H5/微信构建和管理端相关测试；检查改动仅涉及 ProductGroup 专属路径及共享组件的向后兼容属性。
